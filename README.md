# Continual-Learning-4-Yolo

## 1. 项目简介

本项目实现了一个 **基于 YOLOv11 的 Continual
Learning（CL）目标检测实验流程**。
通过分阶段（Stage-wise）训练的方式，在 **尽量保持旧类别检测性能**
的前提下， 逐步引入新类别，验证 YOLOv11 在 CL
场景下的可行性、稳定性以及训练效率。

本实验采用 **人工生成的几何形状数据集**（ring / triangle / rectangle），
用于构建一个 **高度可控、低噪声、可复现** 的 CL 实验环境。

------------------------------------------------------------------------

## 2. 任务定义

### 2.1 学习范式

-   Class-Incremental Object Detection
-   每个 Stage：
    -   类别数量递增
    -   模型参数继承上一 Stage
    -   旧类别仅通过 Replay 部分可见

### 2.2 类别顺序

  |Class ID |  Class Name|
  |----------| ------------ | 
  |0          |ring|
  |1          |triangle|
  |2          |rectangle|


## 3. 数据集说明

### 3.1 数据特性

-   图像尺寸：50 × 50
-   灰度图像（单通道）
-   背景：
    -   随机噪声 或
    -   0 值填充
-   目标形状：
    -   圆环（ring）
    -   三角形（triangle）
    -   矩形（rectangle）
-   目标绘制方式：
    -   thickness = -1 → 填充
    -   thickness ≥ 1 → 轮廓

### 3.2 数据与标签格式

-   图像：PNG
-   标签：YOLO 格式 TXT

目录结构示例：

    dataset/
    ├── images/
    │   ├── 0000.png
    │   └── ...
    └── labels/
        ├── 0000.txt
        └── ...

------------------------------------------------------------------------

## 4. 模型与框架

-   检测模型：YOLOv11-n（Ultralytics）
-   框架：PyTorch
-   训练方式：Stage-wise Incremental Training

YOLOv11 结构逻辑：

    [ Backbone | Neck | Detect Head ]

------------------------------------------------------------------------

## 5. CL 训练流程

### 5.1 Stage 1：Base Task（ring）

**目标**：学习基础检测能力

-   类别：ring
-   初始化：YOLOv11-n 原始权重
-   参数更新：全模型
-   Epoch：300

输出权重：

    stage1_best.pt

------------------------------------------------------------------------

### 5.2 Stage 2：Increment 1（+ triangle）

**目标**：在保持 ring 性能的同时引入 triangle

-   类别：ring + triangle
-   初始化：Stage1 best 权重
-   数据组成：
    -   所有 triangle
    -   ring replay（10%--30%）
-   冻结策略：
    -   Backbone：冻结
    -   Neck + Detect Head：训练
-   Epoch：70

    Classes: [ring, triangle]

------------------------------------------------------------------------

### 5.3 Stage 3：Increment 2（+ rectangle）

**目标**：进一步扩展类别，控制累计遗忘

-   类别：ring + triangle + rectangle
-   初始化：Stage2 best 权重
-   数据组成：
    -   所有 rectangle
    -   ring + triangle replay（各 10%--15%）
-   冻结策略：
    -   Backbone：冻结
    -   Neck：部分解冻
    -   Detect Head：训练
-   Epoch：70

## 6. 参数冻结策略总结

  Stage     Backbone   Neck      Head
  --------- ---------- --------- -------
  Stage 1   Train      Train     Train
  Stage 2   Freeze     Train     Train
  Stage 3   Freeze     Partial   Train

该策略在 **新类可学习性** 与 **旧类保持性** 之间取得较好平衡。

------------------------------------------------------------------------

## 7. 训练参数建议（CL 阶段）

``` python
epochs = 70
lr0 = 1e-3
batch = 16
imgsz = 50

mosaic = 0.0
mixup  = 0.0
cutmix = 0.0
```

> 在 CL 场景下不推荐使用强数据增强，否则会加剧遗忘。

------------------------------------------------------------------------

## 8. 评估方式

-   指标：
    -   mAP@0.5
    -   mAP@0.5:0.95
-   必须按 **类别分别评估**
-   小验证集下 mAP 波动较大，需结合定性结果分析

------------------------------------------------------------------------

## 9. 实验结论（经验总结）

-   YOLOv11 在冻结 Backbone 的条件下可有效支持 CL
-   Detect Head + Neck 提供了足够的新类可塑性
-   新类通常在 3--8 epoch 内收敛
-   合理的冻结策略可显著降低灾难性遗忘

------------------------------------------------------------------------
